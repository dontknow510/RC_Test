## 二、技术栈

- **MCU**：STM32F103C8T6（题 2、3、5 执行端、硬件题 1）、STM32F407VET6（题 4、5 主控端）
- **开发方式**：STM32CubeMX + CMake + CLion / VSCode，HAL 库，arm-none-eabi-gcc
- **上位机与调试**：VOFA+、OLED 显示、串口
- **硬件设计**：嘉立创 EDA 专业版；STM32F103C8T6核心板、LM2596S-5.0（Buck）

## 三、各题实现要点

- **软件 2**：自定义串口协议接收 VOFA+ 下发的目标角度，回传当前角度与 PWM 占空比，并按 JustFloat 帧格式在 VOFA+ 中实时绘图。
- **软件 3**：模块化 `can.c/can.h`；主机按键触发发送 0x11，从机回 0x22 并翻转 LED，主机串口打印收到的数据。
- **软件 4**：ADC 电位器采样（100 ms 周期、16 次平均降抖动）→ 定速 / 定位双模式；定速用速度 PI，定位用「位置 PD 外环 + 速度 PI 内环」串级控制，VOFA+ 记录调参过程。
- **软件 5**：主控端（F407）采集双路电位器 + MPU6050（Kalman 解算姿态），按 100 Hz / 10 字节帧（帧头、长度、序号、模式、双路脉宽、CRC8）经蓝牙发送；执行端（F103）状态机收帧校验后驱动双舵机；两种控制模式实时切换。

## 四、编译与烧录

各子目录均为独立 CMake 工程：用 CLion 或 VSCode + CMake 打开工程根目录，选择 `CMakePresets.json` 中的预设配置构建，ST-Link / DAP-Link 烧录。
依赖：STM32CubeCLT（或 arm-none-eabi-gcc + OpenOCD）、STM32CubeMX（用于修改 .ioc）。
