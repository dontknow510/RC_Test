- 开发方式：STM32CubeMX + HAL 库 + CMake 工程

## 4. 已完成的CubeMX配置

### 4.1 系统时钟

- SYSCLK：168 MHz
- HCLK：168 MHz
- APB1：42 MHz，APB1定时器时钟为84 MHz
- APB2：84 MHz，APB2定时器时钟为168 MHz
- 当前工程使用HSI经过PLL产生系统时钟

### 4.2 TIM9电机PWM

- 通道：TIM9_CH1，输出引脚PE5
- Prescaler：83
- Counter Period：99
- Counter Mode：Up
- PWM Mode：PWM Mode 1
- Pulse：0
- Polarity：High
- PWM频率：约20 kHz

PWM比较值计划直接使用`0~100`：

- `0`表示0%占空比
- `50`表示约50%占空比
- `100`表示100%占空比

### 4.3 TIM4编码器

- 引脚：PD12/TIM4_CH1、PD13/TIM4_CH2
- Encoder Mode：TI1 and TI2，即正交四倍频计数模式
- Prescaler：0
- Counter Period：65535
- CH1 Polarity：Rising Edge
- CH2 Polarity：Rising Edge
- CH1 Input Filter：4
- CH2 Input Filter：4
- 两个通道均为Direct Input、No Division
- TIM4编码器不使用脉冲中断，由硬件自动计数

MG513X具体型号的编码器线数、减速比和输出轴每圈计数尚未确认。在计算RPM前，必须根据电机规格确认每圈总计数CPR，或通过实测输出轴转一圈的计数值进行标定。

### 4.4 ADC1电位器采样

- 引脚：PC0/ADC1_IN10
- Resolution：12 bits
- Data Alignment：Right
- Scan Conversion Mode：Disabled
- Continuous Conversion Mode：Disabled
- External Trigger：Software Start
- Number of Conversion：1
- Sampling Time：84 Cycles
- DMA：Disabled
- ADC原始值范围：0~4095

电位器使用3.3 V供电，因此滑动端输入PC0的电压范围为0~3.3 V。

### 4.5 TIM6控制周期中断

- Prescaler：8399
- Counter Period：99
- TIM6时钟：84 MHz
- 中断周期：10 ms，即100 Hz
- `TIM6_DAC_IRQn`已在NVIC中开启
- 已生成`TIM6_DAC_IRQHandler()`并调用`HAL_TIM_IRQHandler(&htim6)`

TIM6计划作为编码器测速、ADC更新和PID计算的固定控制周期。中断回调中应尽量只做短时间计算或设置任务标志，不要进行OLED整屏刷新和大量串口发送。

### 4.6 USART1

- 工作模式：Asynchronous TX/RX
- 波特率：115200
- 数据格式：8位数据、无校验、1位停止位
- 硬件流控：关闭
- `USART1_IRQn`已在NVIC中开启
- 已生成`USART1_IRQHandler()`并调用`HAL_UART_IRQHandler(&huart1)`

USART1中断目前只完成了CubeMX和NVIC配置，尚未在用户代码中调用中断接收函数，因此现在还不会自动接收PID参数。

### 4.7 按键和OLED

- PE12、PE13、PE14、PE15已配置为GPIO输入和内部下拉
- 按键按下时引脚连接3.3 V，读取高电平为按下
- 按键暂不使用EXTI，计划使用主循环轮询和软件消抖
- I2C2使用PB10/PB11，当前总线速度100 kHz
- OLED暂不使用I2C中断或DMA

## 8. 建议的下一步开发顺序

1. 先启动PWM，使用固定占空比验证TB6612和电机方向。
2. 启动编码器，手动转动电机轴，验证计数是否增减且方向正确。
3. 启动TIM6，每10 ms读取编码器计数增量并计算速度。
4. 读取ADC并通过串口打印原始值，确认电位器范围接近0~4095。
5. 将ADC映射为目标转速，先做开环调速。
6. 加入PID闭环，并通过USART1在线修改Kp、Ki、Kd。
7. 最后加入按键状态机和OLED显示，避免早期调试内容过多。

## 9. 接手注意事项

- CubeMX已经生成初始化函数，但初始化不等于外设已经开始运行。
- USART1打开NVIC后仍需在程序中主动启动中断接收，每次接收完成后通常还要重新挂载下一次接收。
- 不要在TIM6中断中进行阻塞式串口发送、长时间ADC等待或OLED整屏刷新。
- PID采样周期固定为10 ms后，PID参数必须按该周期进行调试。
- TB6612的PWMA只控制占空比，AIN1/AIN2决定电机方向。
- 需要确认编码器输出信号电平与STM32的3.3 V输入兼容。
- 需要确认OLED模块是否自带I2C上拉电阻；若没有，应在SCL和SDA上增加上拉。
- 当前整个`software/4_fan/4fan`目录仍是Git未跟踪内容，尚未提交。
